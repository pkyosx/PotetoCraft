# Hand-off

The last step of every playbook. You report, propose, and stop. The user decides what leaves the machine.

1. Summarize the outcome in a few sentences, leading with what changes for the user.
2. List the evidence: commands run, test output, measurements, screenshots, with paths.
3. List what you did not verify, and why.
4. List the risks and open decisions.
5. Draft each proposed outward action: commit message, branch name, PR title and description, comments or replies. Show them as text.
6. Mention any scratch directories you left in place.
7. Stop and wait for the user to say go. Never commit, push, open a PR, merge, or post on your own. When the user says go, do only the actions they named.

**Reply:** outcome, evidence, unverified items, risks, and the drafts, ending with a clear statement that you are waiting for the user.
